# Suco de Zap — Termo de Risco e Privacidade (Beta)

Antes de conectar seu WhatsApp, você precisa entender e aceitar o seguinte. Sem rodeio.

## 1. Risco real de banimento do seu número

O Suco de Zap se conecta ao seu WhatsApp pelo protocolo do **WhatsApp Web usando uma
biblioteca não-oficial** (o WhatsApp não oferece API oficial para contas pessoais).
O WhatsApp **pode detectar esse uso e banir o seu número — temporária ou
permanentemente, sem aviso**. É raro em uso pessoal moderado, mas acontece e **não
temos como impedir nem reverter**. Se o seu número é crítico para o seu trabalho ou
negócio, **não conecte a conta principal** — use um número secundário ou não use o
produto.

## 2. Onde seus dados ficam

- Suas conversas são sincronizadas para um **servidor privado (não é nuvem pública)**
  e processadas por **IA que roda nesse mesmo servidor** — o conteúdo das suas
  mensagens **não é enviado para OpenAI, Google ou qualquer API externa**.
- **Senhas, tokens e números de cartão nunca são armazenados**: o sistema guarda só
  um ponteiro ("existe uma senha nesta mensagem, neste dia"), com o trecho redigido.
  Isso é regra de código, não configuração.
- Você controla o que é indexado (categorias podem ser desligadas, e desligar apaga
  o que já foi extraído) e pode **pedir a exclusão total dos seus dados a qualquer
  momento** — apagamos o banco inteiro da sua conta.

## 3. Suas responsabilidades

- Suas conversas incluem mensagens de **outras pessoas, que não sabem deste
  processamento**. Ao usar o produto, você assume a responsabilidade por esse uso no
  seu contexto (LGPD trata dados pessoais de uso doméstico de forma diferente, mas a
  responsabilidade pelo uso é sua).
- Guarde seu token de acesso como uma senha: **quem tem o token lê tudo**.

## 4. É beta

Pode ter bug, pode ficar fora do ar, resumo de IA pode errar ou inventar menos do
que gostaríamos, mas ainda erra. Não tome decisão importante baseada só no resumo —
confira a conversa original.

especialmente o risco de banimento do item 1.
